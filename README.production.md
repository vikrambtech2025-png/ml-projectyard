# ML-ProjectYard — Production Deployment

Generated by the ML-ProjectYard production pipeline (evaluation -> testing -> verify deployability).

## Quickstart

```bash
pip install -r requirements.txt
python scripts/fetch_data.py    # downloads the curated Kaggle dataset
python scripts/train.py          # trains and caches a baseline model in models/
python app.py                    # launches the Gradio UI at http://localhost:7860
```

## Interactive UI

`app.py` exposes a human-interactable [Gradio](https://gradio.app) interface. Run it
locally, or launch with `share=True` to get a public link.

## Tests

```bash
python -m unittest discover -s tests
```

## Container

```bash
docker build -t ML-ProjectYard .
docker run -p 7860:7860 ML-ProjectYard
```

## Layout

```
app.py                 # Gradio entrypoint (human-interactable UI)
src/                   # reusable modules (config, model registry)
scripts/fetch_data.py  # downloads the curated Kaggle dataset (kagglehub)
scripts/train.py       # trains + caches the baseline model
scripts/predict.py     # CLI health check for the model registry
tests/                 # smoke tests
data/                  # dataset (downloaded)
models/                # trained/exported model artifacts
Dockerfile             # containerized deployment
requirements.txt       # pinned dependencies
```

## Integration guide

`src/model_registry.py` discovers saved models inside `models/`, `Model/`, `model/`
(any `.joblib`, `.pkl`, `.h5`, `.pt`, `.onnx`). The app falls back to a lazily
trained baseline (`models/baseline.joblib`) for tabular, NLP, and time-series tasks.
To wire the original notebook's model, drop its exported artifact into `models/` and
re-run `python app.py`.

Dataset source: https://www.kaggle.com/datasets//
